# 2. Complete Binary Search Tree

### 一、题目描述

**题目描述：**
二叉搜索树(BST)被递归定义为具有以下属性的二叉树：

结点的左子树中的所有结点值均小于这个结点
结点的右子树中的所有结点值均大于这个结点
左右子树必须是二叉搜索树。
完全二叉树(CBT)是从左到右完全填充的树(可能除了底层之外)。

现在给定一系列不同的非负整数，则可以构造唯一的完全二叉搜索树(CBST)，输出该树的层序遍历序列。

**输入格式：**
第一行输入一个正整数N(≤1000)。然后在下一行给出N个不同的非负整数。一行中的所有数字用空格分隔，并且值不大于2000。

**输出格式：**
打印相应的完全二叉搜索树的层序遍历序列。所有数字用空格分隔，并且行尾不能有多余的空格。

**输入样例：**

```
10
1 2 3 4 5 6 7 8 9 0
```

**输出样例：**

```
6 3 8 1 5 7 9 0 2 4
```

## 二、思路分析

### **2.1 基本概念**

`二叉搜索树`

二叉搜索树就是一个二叉树，然后以它的根结点为中心，左边的元素的值全部都小于根结点，而右边的都比根结点大。二叉搜索树有可能是一颗非常不平衡的树，在极端情况下它有可能是完全左斜的或者是完全右斜的。

![在这里插入图片描述](https://img-blog.csdnimg.cn/545aea09f8ec4aa4ab6426803f208f9d.png)

`完全二叉树`

它是一棵真正的非常平衡的二叉树。如果我们把它的结点从上到下、从左到右一层一层地来标号的话，这些标号从一个都不能少(最后一层最后面可以少几个)。

![在这里插入图片描述](https://img-blog.csdnimg.cn/856a8247e6124a0e8514d10430f3f44a.png)

`完全二叉搜索树`

则包含了上面两棵树的特点，即有序，又平衡。以题目中的输入为例，对应的完全二叉搜索树结构如下：
输入：1 2 3 4 5 6 7 8 9 0
输出：6 3 8 1 5 7 9 0 2 4

### **2.2 采用的数据结构**

解决这个问题之前，我们要决定用什么数据结构去表示最后的这棵完全二叉搜索树。通常表示树都有两种方法：链表和数组。在决定数据结构的时候，通常要跟我们要做的事情是有关联的。在这道题里头，需要做的操作如下

`两个基本操作：`
① 要把数字填到这个完全二叉搜索树里面去。换言之，就是对这棵树里面的每一个结点访问一次，填写一个数字，也就对应的某种遍历。
② 最后我们要对这个树做一个层序遍历的输出。
所以基本的操作都是在对这棵树来做遍历，就遍历的这个操作而言，用链表或者用数组都差不多。如果两种数据结构在时间上，没有谁有明显优势的话，那我们就来看一下空间。

`空间占用`

链表表示一棵树：占用空间少，遍历操作需要使用指针，指针操作较危险且耗时
数组表示一棵树：存在空间浪费，遍历操作简单，直接使用数组下标

`最终采用`

在我们这道题里面，完全二叉树几乎没有一个结点是空的，所以用数组去表示这棵树还是相当划算的。我们最后要层序遍历地输出，用数组的话它本来就是按照层序遍历的顺序存的。我其实什么都不用做，最后直接把这个数组按照它的下标顺序输出就完了。所以我们用==数组==

### **2.3 核心算法**

在一棵二叉搜索树里面，我知道根结点左边的所有的元素都比它小，右边的都比它大。换言之，如果我知道它的左子树一共包含了多少个结点，那我就知道根结点上要放的这个数字一定是从小到大排第几位的那个数字。

```
在这种情况下，首先把输入的序列从小到大排一个序。
```

**先序遍历**

```c
//输入的序列存在数组A中，在递归计算过程中每次需要A的一段
//ALeft为A的一段的最左侧下标
//ARight为A的一段的最右侧下标
/*我们把最后生成的那棵树存在另外一个数组T中，TRoot对应的是当前我们要考虑的这棵子树的根结点所在的位置
*/
//整个函数完成的事情就是：从A段中选出正确的数字，填到T[TRoot]中

void solve( int ALeft, int ARight, int TRoot )
{ /* 初始调用为 solve(0, N-1, 0) */
	//n=当前传进来这A段所包含的元素
	n = ARight – ALeft + 1;
	if (n==0) return; 
	L = GetLeftLength(n); /* 计算出n个结点的树其左子树有多少个结点 */
	T[TRoot] = A[ALeft + L]; //将左子树的根结点写进去
/*
根结点是TRoot的话，那么它的左孩子的下标应该是TRoot*2。
但是你要小心，那是在堆里面，堆的特点是他的第0个元素是不存真实值的，他只存一个哨兵
我们这个结果树里面，根结点是直接放在0里面的，所以他的左孩子就是TRoot*2+1
*/
	//要递归调用左右子树，左子树根结点
	LeftTRoot = TRoot * 2 + 1; 
	RightTRoot = LeftTRoot + 1;
	solve(ALeft, ALeft+L-1, LeftTRoot);
	solve(ALeft+L+1, ARight, RightTRoot);
}

```

## 三、整体代码

```c
#define _CRT_SECURE_NO_WARNINGS
#include<stdio.h>
#include<stdlib.h>
#include<math.h>

int A[1005];
int T[1005];

int min(int a, int b) {
	return a < b ? a : b;
}

int GetLeftLength(int n)//计算出n个结点的树其左子树有多少个结点 
{
	int h = (int)(log2(n + 1));   //向下取整。求出上面的完美二叉搜索树的层数 
	int x = n + 1 - (int)pow(2, h);  //算出除去完美二叉树后剩余的结点数 
	x = min(x, (int)(pow(2, h - 1))); //如果x大于左子树最后一层的最大值，则取最大值，否则不变 
	return (int)(pow(2, h - 1)) - 1 + x; //求出左子树的结点个数 
}

int compare(const void*a, const void*b)
{
	return *(int*)a - *(int*)b;
}

//输入的序列存在数组A中，在递归计算过程中每次需要A的一段
//ALeft为A的一段的最左侧下标
//ARight为A的一段的最右侧下标
//我们把最后生成的那棵树存在另外一个数组T中，TRoot对应的是当前我们要考虑的这棵子树的根结点所在的位置
//整个函数完成的事情就是：从A段中选出正确的数字，填到T[TRoot]中

void solve(int ALeft, int ARight, int TRoot)
{ /* 初始调用为 solve(0, N-1, 0) */
	//n=当前传进来这A段所包含的元素
	int n = ARight - ALeft + 1;
	if (n == 0) return;
	int L = GetLeftLength(n); /* 计算出n个结点的树其左子树有多少个结点 */
	T[TRoot] = A[ALeft + L]; //将左子树的根结点写进去
/*
根结点是TRoot的话，那么它的左孩子的下标应该是TRoot*2。
但是你要小心，那是在堆里面，堆的特点是他的第0个元素是不存真实值的，他只存一个哨兵
我们这个结果树里面，根结点是直接放在0里面的，所以他的左孩子就是TRoot*2+1
*/
//要递归调用左右子树，左子树根结点
	int LeftTRoot = TRoot * 2 + 1;
	int RightTRoot = LeftTRoot + 1;
	solve(ALeft, ALeft + L - 1, LeftTRoot);
	solve(ALeft + L + 1, ARight, RightTRoot);
}

int main()
{
	int N, i;
	int j;
	scanf("%d", &N);
	for (int i = 0; i < N; i++)
	{
		scanf("%d", &j);
		A[i] = j;
	}
	qsort(A, N, sizeof(int), compare);
	solve(0, N-1, 0);
	for (i = 0; i < N-1; i++)
		printf("%d ",T[i]); 
	printf("%d", T[N-1]);
	return 0;

}
```
