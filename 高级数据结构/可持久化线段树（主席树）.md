# 可持久化线段树（主席树）

**重点**

- **值域**线段树，**可持久化**线段树
- 主席树的存储：**动态开点**
- 主席树 == n颗线段树的叠合
- 插入、查询：**双指针同步搜索**
- 区间[l, r]第k小：**前缀和**
- 值域很大：**离散化**
- 时间复杂度：O(nlog^2*n)

==主席树主要解决区间第k大，以及需要查找历史数据的区间问题。==

## 普通线段树与权值线段树的区别

|                | 普通线段树          | 权值线段树         |
| -------------- | ------------------- | ------------------ |
| 节点区间       | 序列的下标区间      | 序列的值域         |
| 节点维护的信息 | 区间最值、区间和 等 | 值域内数出现的次数 |

## 进入主题

**可持久化线段树：**支持回退，访问之前版本的线段树。又称主席树

**主席树的思想**：保存每次插入操作时的**历史版本**

暴力做法，每次开一颗线段树。如图，一次插入序列1， 4， 2， 2。这样内存空间（4n*n）会爆掉。

![image-20220816104504999](C:\Users\44174\AppData\Roaming\Typora\typora-user-images\image-20220816104504999.png)



观察发现，每次只更改logn+1个结点，故只增加更改的结点。

**主席树 == n颗线段树的叠合**

**主席树的存储：**不能使用堆式存储法，应该**动态**开点。（因为存在不同父节点有相同的儿子的情况。）

对于每个节点，应该保存左右儿子的编号

对于每个历史版本，还应该保存根节点的编号。

**内存空间：**初始建树需要开2n-1个结点。有n次插入，每次插入最多增加logn+1个结点。

所以结点总数为2n+n（logn+1）= n（logn+3）

## 操作

### 1.准备操作

```c++
const int N = 200005;
#define lc(x) t[x].l
#define rc(x) t[x].r
int n, m, a[N];
vector<int> v; // 离散化存储容器 
struct Node {
	int l, r;
	int s; // 节点值域中有多少结点 
} t[N*23];
int idx, root[N];
```

### 2. 建树

建空树：递归创建值域[1, n]内的各个节点。

参数：x为当前节点的编号，x是”**传引用**“，通过子空间的x值，给父空间的lc(x) 或 rc(x) 赋值

```c++
void build(int &x, int l, int r) {
    x = ++idx;
    if(l == r) return;
    int mid = (l + r) >> 1;
    build(lc(x), l, mid);
    build(rc(x), mid+1, r);
}
```

### 3. 插入

建主席树：递归建立各个历史版本的线段树。

参数：x为前一版本的结点指针，y为当前版本的结点指针

y是”**传引用**“， 通过子空间y值，给父空间的 lc(y) 或 rc(y) 赋值

```c++
void insert(int x, int& y, int l, int r, int v) {
	y = ++idx;
	t[y] = t[x];
	t[y].s++;
	if(l == r) return;
	int mid = (l + r) >> 1;
	if(v <= mid) insert(lc(x), lc(y), l, mid, v);
	else insert(rc(x), rc(y), mid+1, r, v);
}
```

### 4. 查询区间内第k小的值

简化：求[1, r] 区间内的第k小。找到插入r时的历史版本，在权值线段树上二分搜索就好了。

扩展：求[l, r]区间内的第k小。**可以用前缀和**，[l, r] = [1, r] - [1, l-1]

参数：x为前一版本的结点指针，y为当前版本的结点指针

```c++
int query(int x, int y, int l, int r, int k) {
	if(l == r) return l;
	int mid = (l + r) >> 1; // 双指针同步搜索
	int s = t[lc(y)].s - t[lc(x)].s;
	if(k <= s) {
		return query(lc(x), lc(y), l, mid, k);
	} else {
		return query(rc(x), rc(y), mid+1, r, k-s);
	}
}
```

### 5. 离散化

考虑离散化：值域很大，而数量有限的问题需要用值域做下标。

离散化：把”稀疏的数值“映射成”紧密的下标“。也可以说把”大值域“映射成”小值域“。

离散化三部曲：排序，去重，二分找下标

int getid(int x) { 
	return lower_bound(v.begin(), v.end(), x) - v.begin() + 1;
}

## 模板题：

https://www.luogu.com.cn/problem/P3834

```c++
#include <bits/stdc++.h>
using namespace std;
const int N = 200005;
#define lc(x) t[x].l
#define rc(x) t[x].r
int n, m, a[N];
vector<int> v; // 离散化存储容器 
struct Node {
	int l, r;
	int s; // 节点值域中有多少结点 
} t[N*23];
int idx, root[N];
int getid(int x) {
	return lower_bound(v.begin(), v.end(), x) - v.begin() + 1;
} 
void build(int &x, int l, int r) {
	x = ++idx;
	if(l == r) return;
	int mid = (l + r) >> 1;
	build(lc(x), l, mid);
	build(rc(x), mid+1, r);
}
void insert(int x, int& y, int l, int r, int v) {
	y = ++idx;
	t[y] = t[x];
	t[y].s++;
	if(l == r) return;
	int mid = (l + r) >> 1;
	if(v <= mid) insert(lc(x), lc(y), l, mid, v);
	else insert(rc(x), rc(y), mid+1, r, v);
}
int query(int x, int y, int l, int r, int k) {
	if(l == r) return l;
	int mid = (l + r) >> 1;
	int s = t[lc(y)].s - t[lc(x)].s;
	if(k <= s) {
		return query(lc(x), lc(y), l, mid, k);
	} else {
		return query(rc(x), rc(y), mid+1, r, k-s);
	}
}
int main() {
	scanf("%d %d", &n, &m);
	for(int i = 1; i <= n; i++) {
		scanf("%d", &a[i]);
		v.push_back(a[i]);
	}
	sort(v.begin(), v.end());
	v.erase(unique(v.begin(), v.end()), v.end());
	int vn = v.size();
	build(root[0], 1, n);
	for(int i = 1; i <= n; i++) {
		insert(root[i-1], root[i], 1, vn, getid(a[i]));
	}
	while(m--) {
		int l, r, k;
    	scanf("%d %d %d", &l, &r, &k);
    	int id = query(root[l-1], root[r], 1, vn, k)-1;
    	printf("%d\n", v[id]);
	}
	return 0;
}
```
