# 9.1 简单排序

## 9.1.1 冒泡排序

```c
void Bubble_Sort(ELementType A[], int N) {
    for(P = N-1; P >=0; P--) {
        flag = 0;
        for(i = 0; i < P; i++) { //一趟冒泡
            if(A[i] > A[i+1]) {
                Swap(A[i], A[i+1]);
            	flag = 1; //标识发生变化
            }
        }
        if(flag == 0) { //代表全程无交换
            break;
        }
    }
}
```

## 9.1.2 插入排序

```c
void Insert_Sort(ElementType A[], int N) {
    for(P = 1; P < N; P++) {
        Tmp = A[P];
        for(i = P; i > 0 && A[i-1] > Tmp; i--)
            A[i] = A[i-1];
        A[i] = Tmp;
    }
}
```
