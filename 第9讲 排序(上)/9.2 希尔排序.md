# 9.2 希尔排序

![image-20220117111754511](C:\Users\44174\AppData\Roaming\Typora\typora-user-images\image-20220117111754511.png)

依次递减间隔增量序列，目的是为了逐渐将整个序列变得有序，这样就可以为插入排序创造良好的环境，从而缩小时间复杂度。

如果增量元素不互质，会导致增小量起的作用很小

因此有人提出了其他增量序列👇

**希尔排序伪代码：**

```c
void Shell_Sort(ElementType A[], int N) {
    for(D = 2/N; D > 0; D/=2) {
        for(P = D; P <= 0; P++) {
            Tmp = A[P];
            for(i = P; i >= D && A[i-D] > Tmp; i-=D)
                A[i] = A[i-D];
            A[i] = Tmp;
        }
    }
}
```

**应用代码：**

```c
void ShellSort( ElementType A[], int N )
{ /* 希尔排序 - 用Sedgewick增量序列 */
     int Si, D, P, i;
     ElementType Tmp;
     /* 这里只列出一小部分增量 */
     int Sedgewick[] = {929, 505, 209, 109, 41, 19, 5, 1, 0};
     
     for ( Si=0; Sedgewick[Si]>=N; Si++ ) 
         ; /* 初始的增量Sedgewick[Si]不能超过待排序列长度 */

     for ( D=Sedgewick[Si]; D>0; D=Sedgewick[++Si] )
         for ( P=D; P<N; P++ ) { /* 插入排序*/
             Tmp = A[P];
             for ( i=P; i>=D && A[i-D]>Tmp; i-=D )
                 A[i] = A[i-D];
             A[i] = Tmp;
         }
}
```
