```c
typedef struct TreeNode *BinTree;
typedef BinTree Position;  //二叉树类型

    ElementType Data;  //结点数据
```

### 3.3.1 先序遍历

遍历过程为：

1. 访问根节点：
2. 先序遍历其左子树；
3. 先序遍历其右子树。

```c
void PerOrderTravelsal(BinTree BT) {
    if(BT) {
        printf("%d", BT->Data);
        PerOrderTravelsal(BT->left);
        PerOrderTravelsal(BT->right);
    }
}
```

### 3.3.3 后序遍历

遍历过程：

1. 后序遍历其左子树
2. 后序遍历其右子树
3. 访问根节点

```c

    if(BT) {
        PostrOrderTravelsal(BT->left);
```

## 二、二叉树的非递归遍历

### **示例1：**中序遍历非递归遍历算法

非递归算法实现的基本思路：**使用堆栈**

![image-20211216200135745](C:\Users\44174\AppData\Roaming\Typora\typora-user-images\image-20211216200135745.png)

算法思路：

- 遇到一个接待你，就把他压栈，并去遍历它的左子树
- 当左子树遍历结束后，从栈顶弹出这个结点并访问它
- 然后按其右指针再去中序遍历该结点的右子树

```c
void InOrderTravelsal(BinTree BT) {
    BinTree T = BT;
    Stack S = CreatStack(MaxSize);//创建并初始化堆栈
    while(T || !IsEmpty(S)) {
        while(T) { //一直向左并将沿途节点压入堆栈
            Push(S, T);
            T = T->Left;
        }
        if(!IsEmpty(S)) {
            T = Pop(S);//结点弹出堆栈
            printf("%5d", T->Data);//访问打印结点
            T = T->Right;//转向右子树
        }
	}
}
```

## 三、层序遍历

二叉树遍历的核心问题：==二维结构的线性化==

**队列实现：**遍历从根结点开始，首先将跟结点入队，然后开始执行循环：结点出队、访问该结点、其左右儿子入队

层序基本过程：先根结点入队，然后：

1. 从队列中取出一个元素；
2. 访问该元素所指的结点
3. 若该元素所指向的结点左、右儿子结点排空，则将其左儿子、右儿子的指针顺序入队

```c
void LevelOrderTraversal(BinTree BT) {
    Queue Q;
    BinTree T;
    if(!BT) 
        return;
    Q = CreatQueue(MaxSize);
    AddQ(Q, BT);
    while(!IsEmptyQ(Q)) {
        T = DeleteQ(Q);
        printf("%d\n", T->Left);
        if(T->Left)
            AddQ(Q, T->Left);
        if(T->Right)
            AddQ(Q, T-> Right);
    }
}
```



**应用：**

（1）求二叉树的高度

```c
int PostOrderGetHeight(BinTree BT) {
    int HL, HR, MaxH;
    if(BT) {
        HL = PostOrderGetHeight(BT->Left);//求左子树的高度
        HL = PostOrderGetHeight(BT->Right);//求右子树的高度
        MaxH = (HL > HR)? HL : HR;//取左右子树较大的深度
        return (MaxH + 1);///返回树的深度
    } else {
        return 0;
	}
}
```
