# 4.1 二叉搜索树

## 1.什么是二叉搜索树

二叉搜索树：一棵二叉树，可以为空；如果不为空，满足以下性质：

   					1. 非空**左子树**的所有**键值小于其根节点**的键值。
   					2. 非空**右子树**所有的**键值大于其根节点**的键值。
   					1. **左、右子树都是二叉搜索树。**

## 查找：

思路：![image-20220108115909294](C:\Users\44174\AppData\Roaming\Typora\typora-user-images\image-20220108115909294.png)

```c
Position Find(ElementType X, BinTree BST) {
    if(!BST) return NULL;
    if(X > BST->Data) {
        return Find(X, BST->Right);
    } else if (X < BST->Data) {
        return Find(X, BST->Left);
    } else {
        return BST;
    }
}
```

## 查找最大和最小元素

最大元素一定是在树的最右分支的端节点上

最小元素一定是在树的最左分支的端节点上

![image-20220108120647728](C:\Users\44174\AppData\Roaming\Typora\typora-user-images\image-20220108120647728.png)
查找最小元素的递归函数

```c
Position FindMin(BinTree BST) {
    if(!BST) {
       	return NULL;
    } else if (!BST->Left) {
        return BST;
    } else {
        return FindMin(BST->Left);
    }
}
```

查找最大元素的递归函数

```c
Position FindMax(BinTree BST) {
```
