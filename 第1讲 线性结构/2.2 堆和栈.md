# 堆和栈

## 1.栈的顺序存储实现

栈的顺序存储结构通常由一个一维数组和一个记录栈顶元素位置的变量组成。

```c
#define MaxSize
typedef struct SNode* Stack;
struct SNode{
    ElementType Date[MaxSize];
    int Top;
};
```

1. 入栈

   ```c
   void Push(Stack PtrS, ElementType item) {
       if(PtrS->Top == MaxSize - 1) {
           printf("堆栈满");
           return;
       } else {
           PtrS->Date[(PtrS->Top)++] = item;
           return;
       }
   }
   ```

3. 例：请用一个数组实现两个堆栈，要求最大的利用数组空间，使数组只要有空间入栈操作就可以成功。

   思路：从两边（分别为Top1， Top2）往中间堆数据

   ```C
   #define MaxSize
   struct DStack {
       ElementType Date[MaxSize];
       int Top1;
       int Top2;
   } S;
   S.Top1 = -1;
   S.Top2 = MaxSize;
   void Push(Struct DStack *PtrS, ElemenType item, int Tag) {
       if(PtrS->Top2 - PtrS->Top1 == 1) {
           printf("堆栈满");
           return;
       } 
       if(Tag == 1){
           PtrS->Date[(PtrS->Top1)++] = item;
       } else {
           PtrS->Date[(PtrS->Top2)--] = item;
       }
   }
   ```
